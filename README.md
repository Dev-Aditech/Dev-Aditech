## About Me

I'm a Frontend / Web Developer based in Nigeria with 3+ years of experience building responsive websites and web applications. I focus on writing clean, maintainable frontend code and creating interfaces that feel polished and easy to use.

I turn ideas into functional digital products — from business websites and landing pages to interactive web apps. I work primarily with **HTML5**, **CSS3**, **JavaScript**, and **React.js**, and I use **Firebase** for authentication, databases, and application services when projects need backend functionality.

I'm continuously improving my craft and currently expanding into TypeScript, Next.js, and modern full-stack development practices.
