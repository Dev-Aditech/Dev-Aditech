<div align="center">
  <h2>👨‍💻 About Me</h2>
</div>

<br/>

I'm a **Frontend / Web Developer** based in Nigeria with **3+ years** of experience crafting responsive websites and modern web applications. I started coding professionally and seriously in **2023**, and since then I’ve been focused on building clean, maintainable frontend solutions that deliver real value to users.

My work centers around:

- Creating **responsive** and **accessible** user interfaces  
- Writing **clean**, well-structured frontend code  
- Prioritizing **user experience** and visual clarity  
- Turning ideas into functional digital products  
- Using **Firebase** effectively for authentication, databases, and application services when projects need backend capabilities  

I believe good frontend development is not just about making things look good — it’s about making them work reliably, load fast, and feel intuitive across devices.

I continuously push myself to improve, currently expanding into **TypeScript**, **Next.js**, advanced React patterns, and modern full-stack approaches.
